# Contributing

## Setup

- Node.js **20+**

```bash
npm ci
```

## Dev loop

```bash
npm run start
```

## Quality checks

```bash
npm run format:check
npm run typecheck
npm run lint
npm run test
npm run build
```

## Building distributables

```bash
npm run dist
```

macOS ZIP (recommended for sharing):

```bash
npm run release:zip
```
