# Security Policy

## Reporting a vulnerability

If you believe you’ve found a security issue, please **do not** open a public GitHub issue.

Instead, report it privately (preferably via GitHub’s private vulnerability reporting / Security Advisory flow, if enabled for this repo). If that isn’t available, contact the maintainer privately (for example, via the email address listed on their GitHub profile) with:

- A clear description of the issue and impact
- Steps to reproduce
- Any suggested fix or mitigation

We’ll respond as soon as possible and coordinate a fix + release.

For non-security bugs (crashes, conversion failures, UX issues), please open a normal GitHub issue and include logs if possible.
